Welcome to everybody's favorite arcade game: Space Invaders. Go back to an antique world before 3D technology existed, and play a remastered version of one of the earliest video games!

This is my version of Space Invaders, a classical game where you play as a ship defending yourself against a swarm of invaders!

**VERSION 1 / First Ship**
- Game's base is done
- No restart button
- Game stops upon death, need to reload page to retry
